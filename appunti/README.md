# Appunti PowerShell

Questa cartella contiene gli appunti personali raccolti durante lo studio di PowerShell.

Gli appunti serviranno per fissare i concetti importanti del corso e ripassarli facilmente in futuro. Ogni argomento potrà avere un file Markdown dedicato.

## Argomenti previsti

- comandi e sintassi di base;
- variabili, operatori e tipi di dati;
- pipeline e filtri;
- file, cartelle e permessi;
- script, funzioni e gestione degli errori;
- moduli e automazione.

## Come organizzare gli appunti

Usa nomi semplici e ordinati, per esempio:

```text
01-comandi-base.md
02-variabili.md
03-pipeline.md
```

Ogni file dovrebbe includere una breve spiegazione, esempi di comandi e note personali utili.

> Gli appunti sono in continua evoluzione: verranno aggiornati con il proseguire del corso.
