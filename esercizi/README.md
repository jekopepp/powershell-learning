# Esercizi PowerShell

Questa cartella raccoglie gli esercizi pratici svolti durante lo studio di PowerShell.

## 01 — Informazioni sul PC

Lo script [`01-informazioni-pc.ps1`](./01-informazioni-pc.ps1) mostra alcune informazioni di base sul computer e sulla sessione PowerShell corrente:

- nome dell'utente connesso;
- nome del computer;
- versione di PowerShell;
- cartella dalla quale viene eseguito lo script.

### Requisiti

- PowerShell 7 o successivo.

### Esecuzione

Apri PowerShell nella cartella principale del repository ed esegui:

```powershell
.\esercizi\01-informazioni-pc.ps1
```

### Esempio di output

```text
Utente corrente: jekop
Nome del computer: GAMING
Versione PowerShell: 7.6.5
Cartella corrente: C:\Users\jekop\Documents\GitHub\powershell-learning
```

> L'output può essere diverso in base al computer e alla versione di PowerShell in uso.
